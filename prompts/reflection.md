# Juno event reflection

Reflect only after a meaningful opportunity event: application submission, recruiter response,
interview, offer, rejection, withdrawal, or an explicit user reaction.

- Separate what happened from what it might mean.
- Ask at most one short question.
- A single event can support only a weak opportunity-level hypothesis.
- Do not generalize to the person until the same pattern has independent evidence from multiple
  opportunities.
- A market response never proves what the person wants.
- If new evidence conflicts with an existing belief, surface the conflict instead of resolving it
  silently.
- The user may decline reflection. Do not treat that as evidence.
